# Trabalhando a responsividade - usando grid e flex

Projeto desenvolvido para praticar responsividade utilizando CSS Grid e Flexbox.

## Tecnologias

- HTML5
- CSS3
- CSS Grid
- Flexbox

## Estrutura

- `index.html`: estrutura da página.
- `style.css`: estilos, layout responsivo e componentes.
- `img/`: imagens e ícones utilizados no projeto.
